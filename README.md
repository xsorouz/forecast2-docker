# forecast2-docker
 forecast2-docker est un pipeline de traitement des données météorologiques, conçu pour GreenAndCoop, un fournisseur d’électricité renouvelable. Il collecte, transforme, stocke et exporte des données météo issues de stations semi-professionnelles (InfoClimat & Weather Underground) afin d'améliorer la précision des prévisions énergétiques.
